🔧 Integração futura com a Riot Games API

Este espaço e as funções JavaScript abaixo (ver fetchLiveDataPlaceholder() no código-fonte) estão reservados para as chamadas fetch() reais assim que a chave de desenvolvedor/produção for aprovada. Endpoints previstos de uso (somente leitura, conforme escopo solicitado):

• /val/content/v1/contents — metadados públicos de agentes, mapas, armas e temporadas (sem RSO).
• /val/match/v1/matches/{matchId} — detalhes agregados de partidas (sem RSO, apenas leitura pública).
• /val/ranked/v1/leaderboards/by-act/{actId} — leaderboard público por ato competitivo (sem RSO).
• /riot/account/v1/accounts/by-riot-id/{gameName}/{tagLine} — resolução de Riot ID, exigirá RSO quando vinculado a estatísticas privadas de um jogador autenticado (previsto na fase 2, ver aviso no topo).

Nenhuma chave de API é exposta no front-end; chamadas de produção serão intermediadas por um backend/proxy dedicado, nunca diretamente pelo navegador do usuário.

Roadmap de Conformidade

Fase 1 — AtualDados públicos e simulados, sem autenticação, 100% testável sem login ou download.
Fase 2 — 0 a 30 dias após aprovaçãoSubstituição dos dados simulados por chamadas reais aos endpoints públicos de conteúdo e partidas.
